# Cold Ash color-grading previews

Live in-engine captures (Godot 4.8 dev6, Forward+ on lavapipe) of
`tests/scenes/TestScene.tscn` with the production 33^3 LUTs from
`assets/textures/color_grading/`, regenerated by
`tools/color_grading/generate_cold_ash_luts.py`.

- `HFN_ColdAsh_Night.png` — outdoors, Night profile.
- `HFN_ColdAsh_Shelter.png` — inside the test shelter with the stove lit,
  Shelter profile (the grade switches on `ThermalManager.sheltered_changed`).

Measured against the ungraded frame, Night keeps exposure within ~5% and moves
shadows from warm (blue − red −0.023) to cold graphite-teal (+0.022).
