# Archived Graciosa world

The previous playable island scene, its authored heightmap/source, and its
streaming WorldData are preserved here. Open
`scenes/Graciosa_Island_Terrain.tscn` and press F6 to run Graciosa explicitly.
The scene pins `graciosa.tres`, so the active Key West startup does not change it.

Shared First Exit shelter/bunker assets and gameplay systems remain in their
normal project folders because Key West reuses them. Historical capture/bake
scripts point at this archive. The original scene UID and heightmap bytes are
preserved; height edits still belong in Blender.

The default F5 game now launches `scenes/world/key_west/key_west.tscn`.
